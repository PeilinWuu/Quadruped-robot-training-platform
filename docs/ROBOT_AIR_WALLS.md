# Office 展示机器人空气墙（第一版）

## 人工验收

加载 `scene_yup.sog` / office_01 后，在主视口工具栏“机器人碰撞”中使用：

- 空气墙：默认开启，可关闭作穿透对照。
- 显示碰撞范围：默认关闭。青色为障碍盒，红色为当前命中的障碍类别，黄色为机器人的旋转矩形判定范围（76 × 36 cm）。
- WASD 平移、QE 转向。持续朝障碍移动应停止，斜向移动应沿障碍滑行，反向应能离开。完全挡住时恢复站姿。

优先验收墙壁、沙发、着火圆桌的中心支撑。桌板按高度参与判定，不把桌下空间整体封死。门洞已从墙段中扣除；接近机器人宽度的门洞可能因保守余量较难通过。

## 配置依据

`src/services/robot-collision/officeCollision.json` 是可直接审查、编辑的 37 个固定障碍盒，坐标为 GS 场景未应用整体朝向前的 Y-up 坐标。每个盒包含中心 X/Z、水平半尺寸、高度上下限和绕 Y 方向对应的平面角。

`scripts/export-office-collision.py` 从现有 `D:/interiorgs_data/office_01/structure.json` 墙体/门洞，以及 `semantic_bridge_all/objects_material_catalog.json` 家具包围盒生成初始配置。墙体、沙发使用现有结构范围；桌子 65、66 使用桌板加四角支撑近似，113 使用桌板加中心支撑近似。支撑形状是展示代理，不是重建网格。修改 JSON 后不要重跑导出覆盖人工调整。

没有配置椅子、全部桌子、装饰隔断等物体。当前通过场景显示名 `office_01` / `scene_yup` 匹配启用，其他场景不套用该配置。它是前端运动展示约束，不是 MuJoCo 接触，也不影响后台仿真的位姿流。

## 实现

在 `robotMotionPlaybackService.update` 更新坐标之前注入移动约束。水平占地改为 76 × 36 cm 的旋转矩形（站姿网格约 71 × 32 cm），随机器人朝向和标定缩放变化。在机器人及障碍矩形的四组分离轴上做连续 SAT 检查，移动受阻后沿接触面投影剩余位移，最多处理四次接触。转身分成不超过 0.01 rad 的角度区间，以扩张的中间朝向矩形包住整个角度区间，阻止转身穿墙。完全无法转动时也停止踏步。

障碍和机器人共享场景整体朝向。先将运动坐标经机器人的独立标定变换映射到该公共坐标系，再把约束结果变换回去；平移、偏航和统一缩放适用于此水平运动模型。倾斜机器人标定并非本版主要支持场景，任意倾斜姿态不等价于完整三维碰撞。机器人高度仍由原有贴地逻辑决定，不实现爬越、碰撞力或跌倒。

加载/重置导致初始位置落在代理中时，仅允许朝最近出口移动，不自动弹到障碍另一侧。关闭开关立即恢复原移动方式。场景卸载禁用空气墙，runtime 销毁移除运动约束回调。调试轮廓只参与显示，不进入 GS 深度捕获。

## 验证与后续

139 项前端测试通过。新增测试覆盖薄墙快速穿越、双向阻挡、斜向滑动、后退、桌板高度、旋转盒、墙角和初始重叠退出，以及完全受阻时停止步态。

`node scripts/verify-robot-collision.mjs` 使用真实 SOG 检查墙体、桌子支撑、关闭对照、平移与 1.2 倍缩放标定、场景卸载。截图与数值报告在 `tmp/robot-collision-results`。浏览器检查完成后再运行 `npm run tauri -- build`，避免同时访问生成机器人资源造成 Windows 文件锁。

后续可将多视角 GS 深度投影回场景空间，过滤地面、积累障碍候选，再经人工确认写入这份独立配置。当前不依赖深度面板开关和观察相机，也没有自动融合深度。

本轮同时修正旧高度图的 X/Y 数组索引顺序。未改变高度图数据、三点平面标定和贴地模型，台阶方案见 GROUND_STEPS_PLAN.md。
