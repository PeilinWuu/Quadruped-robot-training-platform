# 当前状态与后续方向

[文档索引](README.md)

以下是研究方向，不是交付时间承诺。已实现与人工验收状态以具体提交和测试记录为准。

## 当前可用

- GS 场景导入、真实深度、GPU 火焰遮挡。
- V1 多点火场展示与相对热像；V2 保留为实验选项。
- Go2 展示、旋转矩形空气墙、旧地面索引修复。
- 卡座入口台阶局部四足站立 IK 样例，待进一步视觉反馈。
- 独立 MuJoCo/平地 MPC 原生模块和测试。

## 展示与协作下一步

1. 人工校准台阶接触面，加入支撑/摆动相位、足端抬升和连续跨阶。
2. 扩充经确认的地面/障碍代理，处理椅子和复杂边缘；避免依赖当前相机生成不稳定碰撞。
3. 把研究验收脚本的本机路径改成统一配置，提供可分发且许可清晰的最小测试场景。
4. 明确原生仿真发行配置与项目统一许可证。

## 训练与真实感知阶段

独立设计训练数据后端，解决场景物理几何配准、传感器标定/噪声、热辐射与材料模型，再考虑自主搜索、规划、ROS 2/实体 Go2 和 Sim-to-Real。不要把前端视觉近似转换为“真实标签”后直接进入训练。
