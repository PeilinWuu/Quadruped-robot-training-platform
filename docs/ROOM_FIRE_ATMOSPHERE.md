# 主界面火场氛围（2026-09-09）

本轮仅用于 office_01 主界面展示，不输出训练数据，也不改变物理仿真、机器人输入或 V1 火焰着色器。

在桌面应用点击「启动多点火场」，「火场氛围」默认开启，可随时取消以对照原效果。
新增世界坐标中的柔和上升烟柱和顶部薄烟层，火点附近带微弱暖色。
烟层在播放开始后约几十秒内缓慢加重并趋于稳定，不随火焰往返播放倒退。
暂停会冻结烟雾运动，重置会恢复初始薄烟；退出多点模式会释放资源。

使用已有占据几何深度约束新增烟雾。深度不可用时隐藏该效果；原有 V1 火焰的遮挡限制仍然存在。
此轮暖色仅是烟雾着色，不是高斯家具表面的动态重新照明。没有实现炭化或真实烟气流动。

验证：118 项既有前端测试通过，新增展示时钟测试单独验证。
`scripts/verify-room-atmosphere.mjs` 使用实际 SOG 和生产渲染代码，生成相同暂停帧的开关对照截图，
覆盖暂停、重置、第一视角和退出清理。RTX 4060 Laptop、1280×720、Edge WebGL2 三处约 60 FPS；
这些是浏览器验证数据，不代表已完成安装版人工视觉验收。
截图及报告在 `tmp/room-atmosphere-results/`。

安装包由 `npm run tauri -- build` 生成，包含播放数据和烟雾所需代理几何。
